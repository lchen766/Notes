    - State: `dp[i] = cost[i] + min(dp[i-1]+1, dp[i-2]+4, dp[i-3]+9)`

    - Key takeaways:
        - Always think: **“last step comes from where?”**
        - Handle base cases carefully (`i = 1,2,3`)
    - Important bug:
        - `costs` is **0-indexed**, but problem is conceptual 1-indexed
        - Correct usage: `costs[i - 1]`
