### System Design: 
- Learned Content Delivery Network (CDN) fundamentals
    - CDN is a globally distributed caching system that serves content from edge servers closest to users
    - Reduces latency, improves performance, and offloads traffic from origin servers
    -Key concepts: edge servers, cache hit/miss, TTL, geo-routing
- Learned Stateless Web Tier architecture
    - Servers do not store user state; each request is self-contained
    - Enables horizontal scaling, high availability, and simplified load balancing
    -User state is externalized (e.g., Redis, database, or JWT)
- Learned Cache reliability & failure mitigation
    - Avoid Single Point of Failure (SPOF) by using multiple cache servers
    - Use overprovisioning (extra memory buffer) to handle traffic spikes and prevent excessive eviction
    - Prevents cache breakdown and reduces database pressure
